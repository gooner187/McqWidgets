ASCII table

The denary, hexadecimal and binary code for every ASCII character.

Binary:

0–31 Control codes

You don’t need to learn these. They aren’t letters, numbers or symbols: they are instructions. Most were made for teleprinters and early computer links, so only a few are still used today.
